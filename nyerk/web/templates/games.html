Party finders shared with other servers

Several servers can run one party finder together. One server's game is the home: its classes, dungeons, gear scores and parties are used. Every linked server shows the same parties and sign-ups in its own party channel, with its own roles; pings stay in each member's own server. Listings show which server each member is from. Either side can unlink at any time.
